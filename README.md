# 🎲 Random Number Generator

This is a simple Python project that generates a random number between two numbers entered by the user.

## Features

- Generate a random number
- Choose your own range
- Easy to use
- Beginner-friendly

## Requirements

- Python 3

## How to Run

```bash
python main.py
```

## Example

```text
Enter the minimum number: 1
Enter the maximum number: 100

Generated Number: 57
```

## Why I Made This

I created this project while learning Python to practice user input and the `random` module.
